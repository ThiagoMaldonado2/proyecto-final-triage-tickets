# Proyecto Final: Triage de Tickets de Soporte con IA

Sistema de automatización que clasifica tickets de soporte usando IA, los enruta según prioridad y requiere aprobación humana antes de responder al cliente.

## Tecnologías
- **Orquestador:** Make
- **Base de datos:** Airtable
- **IA:** OpenAI (GPT-4o-mini)
- **Canal de salida:** Slack + Gmail
